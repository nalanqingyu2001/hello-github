# hello-github

我的第一个 GitHub 项目，用来练习 Git 的基本流程。

## 这个项目是什么

一个极简的示例仓库，包含：

- `README.md` —— 项目说明（就是本文件）
- `hello.py` —— 一个打印问候语的 Python 脚本
- `.gitignore` —— 告诉 Git 哪些文件不要提交

## 运行

```bash
python hello.py 你的名字
```

输出：

```
你好，你的名字！这是从 GitHub 克隆下来的代码。
```

## 我学到的东西

1. `git add` 把改动放进暂存区
2. `git commit` 把暂存区存成一个版本
3. `git push` 把本地版本上传到 GitHub
4. `git pull` 把 GitHub 上的新改动拉回本地
